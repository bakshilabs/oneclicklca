    Approach

    Working principles

    Start from evidence

    Each positioning choice should point to a buyer interview, a deal or a record in the CRM. I would listen to buyers and sellers before changing any message.

    Fewer full launches

    A tiering rule, agreed with product, sets how much effort each release gets. Only a few releases a year get the whole company behind them.

    Material sellers can use alone

    A battlecard is ready when a seller has used it on a call without help. Partners get the same material.

    One measure per launch

    Each launch has a single measure, agreed with sales before release, so we can judge whether it worked.
